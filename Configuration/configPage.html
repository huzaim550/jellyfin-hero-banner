Hero Banner

Adds a rotating hero banner of the latest additions per library to the home screen. The banner reads its settings when it loads, so a browser that is already open picks the changes up the next time it loads or refreshes Jellyfin.

How long each title stays on screen before the banner rotates (3-60).
Number of most recently added items to display (1-20 per library).
Comma-separated library names. Leave blank to include every library.
Comma-separated library names to always leave out.
